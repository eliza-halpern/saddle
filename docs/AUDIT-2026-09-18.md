## 0. How to read this document

Every row below is one of:

- **VERIFIED** — reproduced this session by reading the named line or running the
  named command. The line number is the evidence; if the line has moved, re-grep the
  quoted text before acting.
- **MEASURED** — backed by a run log, an F-number in the benchmark findings, or a
  journal record. Cited by path.
- **CLAIMED** — asserted in a document with no evidence in the repo. Treated as
  false until a test or run shows otherwise (CLAUDE.md, "Defect claims require
  discrimination evidence").

Line numbers are for `52a0e05`. Nothing in this audit has been fixed; the fixes are
work items in `WORKPLAN.md`, one finding to one item.

Viability labels used in §8:

- **PROVEN-IN-PRODUCTION** — the mechanism ships in a widely used tool, or this
  repo's own runs show it working end to end (cite the run).
- **PUBLISHED-WITH-MEASUREMENT** — a paper or report gives an effect size for the
  mechanism, but it has not run in this stack.
- **SPECULATIVE** — a blog post, an unmeasured design argument, or a citation that on
  inspection does not support the claim made for it.

### 9.2 What the workflow added that the local audit lacked

- **The grammar cannot fix v3's failure class.** Hunk headers `@@ -a,b +c,d @@` carry
  line counts that must equal the number of following lines; that is a counting
  constraint outside any context-free grammar. `error: corrupt patch at line 12`
  (every sealed v3 attempt, `../saddle-bench/runs/t1-saddle/.saddle/proofs.jsonl`)
  therefore remains representable under `DIFF_GRAMMAR`. `_apply_diff` already passes
  `--recount` on every rung (`slice.py:165`), so the practical mitigation exists; T4-1
  measures whether it is enough, and #61 (search/replace blocks) stays open as the
  contingency.
- **The property-gate literature has moved.** PGS v2 measured on a 32B open model, which
  is the closest published analogue to this project's 27B worker; the number to cite is
  87.0 vs 63.0 (N=100), not 83/62.
- **Capability and cheating are not monotone.** SpecBench (weaker cheats more) and
  ImpossibleBench (stronger cheats more) disagree; the repo's D3 framing should present
  both rather than the one that supports it.
- **Test-writing failure rates for ~27B models** are now quantified: ~41% single-shot
  pass on arXiv 2603.23443's mutants; TEBench (2605.06125) F1 45.7–49.4%; the "test node
  writes its own oracle" hazard (#44, F5) has an external number.
- **New sources with a use here** (confidence in parentheses; none change a Tier 0–2
  item): xgrammar-2 blog 2026-05-04 (high; engine roadmap), aider unified-diffs page
  (high; PROVEN-IN-PRODUCTION edit format for #61), MUTGEN arXiv 2506.02954v2 (medium;
  LLM-generated mutants vs mutmut, relevant to T2-4's basis field), pytest-timeout
  docs (high; per-test hang detection, an alternative to `SHELL_TIMEOUT`), Weaver
  2506.18203 (medium; weak-verifier ensembles), Qwen3.8-27B HF README (high; the
  worker's documented reasoning-effort semantics), arXiv 2604.27296, 2604.26102v2,
  2510.18327v1, 2605.08680, 2605.26128, 2604.03616, 2604.24712, 2607.22880, 2512.02304,
  2604.14437, 2607.22883, Cleverest 2501.11086 (low–medium; corroborating, not cited in
  the workplan).
